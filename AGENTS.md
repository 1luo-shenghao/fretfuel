# FretFuel project instructions

Scope: all FretFuel project work, including the GitHub theme, Shopify theme copies, local previews, documentation, assets, configuration, and ZIP packages.

- Prepare every proposed change on a dedicated branch and open a pull request for the user to review. Do not make direct changes to the shared checkout or deliver an edited copy or ZIP in place of a PR.
- Never push directly to main or another base branch. Changes may be pushed only to their PR branch.
- Never merge a pull request, enable auto-merge, or arrange for anyone else to merge on the user's behalf. The user personally performs every merge.
- Preserve existing work when preparing a PR. Report the PR link and verification, then leave the merge to the user.
- Do not publish project changes from an unmerged PR.
